# GenesisRoguelike

C# で開発している、データ指向設計（DOD）を意識したプロトタイプのプロシージャル・ローグライクゲームです。
プレイヤーの行動によって世界が変化する「創世（Genesis）」のシミュレーションをコアに据えています。

##  特徴
- **データ指向のマップ管理**: 1D配列（Flat Array）ベースの軽量なマップ構造
- **環境シミュレーション**: ダブルバッファリングを用いた、暴走しない自然な「炎の燃え広がり」システム
- **ノイズによるマプ生成**: FastNoiseLiteを用いたマップ生成
